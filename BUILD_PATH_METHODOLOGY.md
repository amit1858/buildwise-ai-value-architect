# Build path methodology

BuildWise scores Low-code, Pro-code, and Hybrid paths against the actual workload and constraints.

## Low-code

Prefer when connector reuse, fast piloting, and operations ownership matter more than custom runtime control. Validate platform limits, data boundaries, escalation handling, and portability before scale-up.

## Pro-code

Prefer when custom retrieval, evaluation, privacy, provider abstraction, latency control, or regulated logic requires engineering ownership. Define interfaces, observability, deployment, and rollback before implementation.

## Hybrid

Prefer when business users need a governed operational surface while engineering owns intelligence services, retrieval, policy enforcement, or evaluation. Make the contract between the two layers explicit.

The recommendation is a fit assessment, not a permanent lock-in. Users can switch paths; downstream workflow, cost, and build-kit outputs must recalculate from the selected path.
