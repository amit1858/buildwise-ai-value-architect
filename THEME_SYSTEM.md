# Theme system

BuildWise supports Light, Dark, and System theme preferences. The provider surface uses scoped `.bw-*` semantic classes so provider controls inherit token-aware backgrounds, borders, foregrounds, selected-state contrast, and keyboard focus treatment without imposing a global dark-surface override.

Radius rules: major panels use 14px, nested panels use 8px, controls use 7px, and status labels are compact pills. The selected provider remains readable in both explicit Light and Dark selections.
